# Ordre de préparation imprimable

## Route

```text
/preparations/{id}/impression
```

## Usage

L’ordre peut être :

- imprimé sur papier ;
- enregistré en PDF via la boîte d’impression du navigateur.

## Format

- A4 paysage ;
- marges de 10 mm ;
- lignes de tableau non coupées entre deux pages autant que possible ;
- boutons masqués à l’impression.

## Données affichées

Le document reflète uniquement les données déjà enregistrées dans la
préparation. Il ne modifie aucune donnée métier.

# Workflow de remplacement — étape A

## Déclenchement

Une proposition peut être créée uniquement pour une ligne :

- `INDISPONIBLE` ;
- ou `REMPLACEMENT_REFUSE`.

## Données de la proposition

- article différent de l’article demandé ;
- emplacement actif ;
- lot obligatoire pour un béton ;
- quantité strictement positive ;
- commentaire obligatoire.

## Décision

Peuvent accepter ou refuser :

- le demandeur de la préparation ;
- un administrateur technique ;
- un administrateur COREF ;
- un responsable logistique ;
- un responsable de production ;
- un chargé d’affaires.

## Effet de cette étape

L’acceptation confirme uniquement la décision métier. Elle ne modifie pas
encore la réservation ou le stock.

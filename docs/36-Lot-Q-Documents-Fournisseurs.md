# Lot Q — Documents fournisseurs

Le Lot Q remplace progressivement les simples références texte des lots béton
par de vrais documents consultables et persistés.

Le stockage en base est volontaire : le projet Docker actuel ne dispose pas
d'un volume documentaire persistant fourni dans la base du lot Q.

La conformité Béton exige CERTIFICAT + FDS. Les documents peuvent en outre
être rattachés techniquement à un fournisseur, une commande ou un article via
l'API, ce qui prépare l'extension documentaire hors Béton.

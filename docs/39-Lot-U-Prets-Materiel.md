# Lot U — Prêts matériel

Le prêt porte sur les équipements individualisés du module Matériels.
Il ne génère pas de mouvement de stock article : l'équipement existe comme
immobilisation/logistique individuelle.

Le statut du matériel est synchronisé :
`DISPONIBLE → EN_PRET → DISPONIBLE / EN_MAINTENANCE / HORS_SERVICE`.

Les prêts peuvent être rattachés à une personne COREF et/ou à une affaire.
